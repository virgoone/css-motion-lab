Installation

02 / Anatomy

One value drives three layers

  1. --pill-progress moves the colored field and the SVG frontier using transforms.
  2. --pill-count updates the tabular percentage through a CSS counter.
  3. Each frontier uses a different SVG profile and a small vertical breathing cycle.
